How to使い方

  1. 上で「意見論述」か「要約」を選び、問題を選びます。
  2. 解答欄に英文を書きます。語数メーターが緑になれば目安の語数です。
  3. 「添削して採点する」で、AIが英検の4観点（16点満点）で採点・添削します。AIが使えないときは「セルフチェック」で自己採点できます。
  4. 模範解答や修正版を読み上げで聞き、音読・シャドーイングで表現を身につけます。

AI添削には各自の Claude API キーが必要です（「⚙ 設定」から登録）。 下書きと記録はお使いのブラウザにだけ保存され、ほかの人には見えません。
